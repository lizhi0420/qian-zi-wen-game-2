# 千字文 国风识字奇遇记

已移除汉字翻翻乐及有声绘本功能，包括对应首页入口、导航、页面路由、组件与提示文案。

已按《千字文精注本.docx》录入 8 期、125 单元、1000 组汉字与拼音，保留文档中的读音及轻声。原有前 5 课详细释义和组词保留；后续课程只补入原文字音，不编造组词或完整释义。

## 启动

需要 Node.js 22.12 或更高版本。

```sh
npm install
npm run dev
```

浏览器打开 http://localhost:3000 。识字和拼音数据已经保存在代码中，不需要上传 Word 文档或配置 API 密钥。语音朗读使用浏览器语音服务。

## 数据文件

- src/data/qianziwenData.ts：页面直接使用的完整汉字和拼音数据。
- src/data/qianziwenSource.json：从精注本提取的逐字拼音及分期，是生成数据的来源。
- src/data/qianziwenDetails.json：原有前 5 课详细内容。
- scripts/generate_qianziwen.js：从上述文件生成完整数据，可从任意工作目录运行。

修改源数据后运行 `npm run generate:data`。

## 喇叭朗读优化

识字喇叭与跟读示范直接朗读汉字，不再念出拼音提示文字及拉丁拼音。优先使用中国大陆普通话音色；连续点击会替换旧朗读；停止、静音和切换页面时会中断旧朗读，并阻止已取消语音的回调重新启动。声音效果由设备提供的语音服务决定。新增了相应模拟语音回归验证。
## 逐课国风水彩配图

125 课分别配置一张独立的水彩插画，画面根据各课原文主题生成。识字馆显示当前课完整插画，朗读堂采用同课淡色背景；拼音、听音、排序等练习页也随当前课程切换背景。背景遮罩保持文字区域清晰，减少动态效果的系统设置会关闭切换淡入动画。

图片使用内置 image_gen 工具逐课生成，统一要求宣纸肌理、青绿山水、暖赭淡金及古代中国生活场景，不绘制文字。每课提示词和对应诗句保存在 src/data/lessonArtwork.json；图片位于 public/assets/lessons/lesson-001.jpg 至 lesson-125.jpg，已经嵌入项目，无需图片生成 API 或外部图片服务。交付图片经过 JPEG 格式压缩以减小体积。
